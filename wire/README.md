# Packet layout (wire layer)

- **wire_layout.txt** – Wire (Windows client) layout dump. Used by `tools/gen_packet_wire.py` to generate encode (our → wire) and decode (wire → our) for packet structs. Currently contains **sAU_LOGIN_RES** (795-byte Windows layout). To support Char server ↔ client, add Windows layout dumps for Char packet structs (e.g. **sCU_LOGIN_RES**, **sCU_CHAR_SERVERLIST_RES**, **sUC_LOGIN_REQ**) in the same clang-dump format.

- **our_layout.txt** – Our (Linux) layout dump. Same format as wire_layout. Seed data has **sAU_LOGIN_RES** only (839-byte Linux layout). To get a full dump of all protocol structs on Linux, run from project root:
  ```bash
  python3 tools/gen_packet_wire.py --dump-stub
  ```
  This preprocesses `wire/PacketLayoutDump.cpp` and runs clang `-fdump-record-layouts`. If the stub compiles (all protocol names have a matching struct), `wire/our_layout.txt` is overwritten with the full dump. If it fails (e.g. protocol/struct name mismatches in some headers), `our_layout.txt` is left unchanged. The generator only adds conversion for structs that appear in **both** wire_layout.txt and our_layout.txt.

- **PacketLayoutDump.cpp** – Generated by `--dump-stub`; one `sizeof(struct)` reference per protocol to force layout dump. Do not edit by hand.

After updating either layout file, rebuild the project; CMake runs the generator and recompiles `PacketWireLayout.generated.cpp`.
